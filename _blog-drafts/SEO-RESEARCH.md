## Top Competitors Ranking for Core Keywords

### Query: "AI coding for kids Singapore"

**Top 5 ranking sites:**
1. **The Young Maker** (theyoungmaker.com) — "Singapore's leading coding, robotics & AI school for kids"
2. **Coding Lab Singapore** (codinglab.com.sg) — "Award-winning coding school, MIT-inspired curriculum"
3. **The Lab** (thelab.sg) — "Future-proof skill development, problem-based learning"
4. **Computhink** (computhink.com.sg) — "Machine learning camp, coding AI for kids"
5. **Lyza Education** (lyzeducation.com) — "AI and coding enrichment, Meta/Amazon founder experience"

**Content pattern:** All emphasize **curriculum credibility** (MIT, structured pathways) and **age-based tracks** (4–18). Word count: 800–1,500 per page.

**Positioning gaps:**
- None mention **MOE EdTech Masterplan 2030** or **4 AI Learns** framework explicitly
- All focus on "learning to code" not "shipping real apps"
- No competitor mentions **portfolio-building for DSA/EAE** as a primary benefit
- Cost/pricing absent (likely intentional—phone inquiry model)
- No real student project examples visible

### Query: "coding class for teenagers Singapore"

**Top 5 ranking sites:**
1. **Coding Lab Singapore** (second mention)
2. **LCCL Coding Academy** (lcclcoding.com) — "Earliest SG coding school, est. 2012"
3. **SG Code Campus** (sgcodecampus.com) — "Ages 13–18, app development and data analytics"
4. **Global Education Hub** (globaledu.com.sg) — Broad enrichment provider
5. **Kodecoon Academy** (kodecoon.com) — "Progressive curriculum, Scratch to JavaScript"

**Content pattern:** Heavy emphasis on **age-gating** ("Sec 1–4 classes") and **curriculum depth** (Scratch → Python → JavaScript progression). Fewer explicit mentions of outcomes.

**Positioning gaps:**
- No mention of **AI tools** (Claude, Lovable, Cursor) as a teaching method
- No articulation of **DSA/EAE pathway**
- No comparison of "learn to code" vs "ship real apps"
- Missing Singapore school partner lists (major credibility signal)

### Query: "vibe coding singapore"

**Result:** No Singapore-specific results. Global results mention Appwrite, Till Freitag's blog, Coursera specializations. Vibe Makers is currently untapped keyword territory.

**Opportunity:** This is wide open. First-to-rank in SG context wins.

### Query: "MOE EdTech Masterplan 2030 parent guide"

**Result:** Official MOE pages only (moe.gov.sg, learning.moe.edu.sg). No third-party educational content.

**Opportunity:** High-value long-tail. Any parent-friendly explanation of MOE's 4 AI Learns is underserved.

### Query: "DSA portfolio app development Singapore"

**Top 5 ranking sites:**
1. **Code Ninja** (codeninja.com.sg) — "DSA & EAE coaching, portfolio & interview prep"
2. **Ryse Edu** (ryse-edu.com) — "DSA & EAE coaching"
3. **Elixir Academy** (elixirtuition.com) — "DSA preparation, art portfolio guidance"
4. **Overmugged.com** — Student guide blog
5. **TutorRoll** — Tutoring directory

**Content pattern:** Heavy education-services marketing (coaching ads). Few articles that explain **why a tech portfolio matters for DSA** in practical terms.

**Positioning gaps:**
- No content that says "here's a real app a student built, and here's how it helped their DSA"
- Missing narrative: "This is what top schools look for in a portfolio"
- No competitor is positioning **first tech project** as an accessible DSA differentiator

## Key SEO Insights for Vibe Makers

### 1. **MOE Framework Positioning is Untapped**
No competitor is riding the MOE 4 AI Learns narrative. This is a *direct* competitive moat for Vibe Makers because:
- Parents are actively searching for MOE alignment ("how does this help with the curriculum?")
- Vibe Makers explicitly maps to the framework
- First mover advantage in SG context

**Action:** Ensure every blog post links to the MOE 4 AI Learns article. Make it the "hub" post.

### 2. **Real Portfolio Examples Win**
Competitors talk about portfolio-building. Vibe Makers *shows* portfolio examples with specificity. This is a credibility multiplier for DSA-seeking parents.

**Action:** Update the 5 student apps post quarterly with new real examples. Keep it fresh.

### 3. **"Vibe Coding" is White Space**
No Singapore company is owning the term "vibe coding." Vibe Makers should aggressively own it for local SEO.

**Action:** Every post should use "vibe coding" 2–3 times. Internal link to the "What is vibe coding?" hub.

### 4. **AI Tools Comparison Gap**
No competitor has published a detailed, teen-friendly comparison of Lovable vs Cursor vs Claude vs ChatGPT. This is a high-value piece.

**Action:** Promote this aggressively on social. It's a natural share-piece for parents confused about tool choice.

### 5. **DSA/EAE Pathway is Under-Served**
Parents are actively looking for "how do I get my kid into a good JC?" content. Vibe Makers can own the "tech portfolio for DSA" angle.

**Action:** Write follow-up posts on specific DSA successes / interview talking points.
