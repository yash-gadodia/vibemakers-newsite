# vibemakers-newsite

Static homepage prototype for vibemakers.dev, hosted on Railway.

- Source HTML: `index.html` (single self-contained file — fonts via CDN)
- Served by [`serve`](https://www.npmjs.com/package/serve) on `$PORT`
- Deploy: push to `main` → Railway auto-deploys

## Local preview

```bash
npm install
npm start
# open http://localhost:3000
```
